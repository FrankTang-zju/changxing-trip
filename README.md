# 长兴一日行程 · 主题党日活动

杭州拱墅出发，包车往返长兴的一日行程方案。上午参观新四军苏浙军区纪念馆与江南红村，
中午在仰峰村用餐，下午游八都岕十里古银杏长廊，17:30 返杭。

- 主选日期 2026 年 11 月 21 日（周六），备选 11 月 22 日（周日）
- 单页 HTML，无外部依赖，图片存放在 `assets/`
- 内容含：速览、时刻表、上午（纪念馆 + 十处旧址）、午餐、下午、预算、注意事项

## 在线访问

启用 GitHub Pages 后，地址为 `https://<用户名>.github.io/<仓库名>/`。

## 更新方式

直接修改 `index.html` 或替换 `assets/` 里的图片，提交推送后刷新页面即可：

```bash
git add -A
git commit -m "更新行程"
git push
```
